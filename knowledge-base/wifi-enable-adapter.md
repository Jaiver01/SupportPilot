# Conexión WiFi - habilitar adaptador

## Escenario recomendado para este procedimiento

Aplicar cuando el adaptador WiFi aparece **desactivado** y el usuario reporta:

- "No veo redes WiFi"
- "El botón de WiFi está en off"
- "No puedo activar el WiFi"

## Procedimiento

1. Abrir configuración de red del sistema operativo.
2. Verificar estado del adaptador inalámbrico.
3. **Habilitar** el adaptador WiFi.
4. Confirmar que aparezcan redes disponibles.
5. Conectarse al SSID corporativo e ingresar credenciales.
6. Validar navegación y acceso a recursos internos básicos.

## Notas operativas

- Si el adaptador vuelve a deshabilitarse automáticamente, revisar políticas de energía/controlador.
- Si no aparecen redes tras habilitar, validar driver y hardware.

## Criterios para escalar

- El adaptador no permite habilitarse.
- El adaptador no es detectado por el sistema.
- El usuario continúa sin conectividad tras habilitar y reconectar.
